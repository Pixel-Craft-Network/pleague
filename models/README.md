# Pixel League models

- `rocket-racer.obj` — low-poly, forward-facing (+X) player car shell. The game adds team paint, glass, wheels, lights, spoiler details, and boost exhaust at runtime.
- `pixel-ball.obj` — triangulated match ball with separately named light and dark panel groups.

Both OBJ assets are original, editable text meshes. The arena, goals, boost stations, stadium structure, and lighting are assembled from reusable Three.js geometry in `src/scene3d.js`.
